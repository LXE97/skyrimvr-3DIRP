## SKSE plugin source for Skyrim VR mod: [3D Interface Replacement Project](https://www.nexusmods.com/skyrimspecialedition/mods/186015)

### User requirements:
* SKSE
* Skyrim VR Tools
* Address Library VR v235 minimum
